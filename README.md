## What is PicxCraft?

**PicxCraft** is a free online image editing toolkit with **114+ tools** that run entirely in your browser. Every tool uses the HTML5 Canvas API and WebAssembly to process images **client-side** — your images are **never uploaded to any server**, making PicxCraft the most private image editing solution available online.

Whether you need to **compress images to 100KB**, **resize photos for Instagram**, **convert PNG to JPG**, **remove backgrounds**, **create passport photos**, or **extract text from images with OCR** — PicxCraft has a tool for it. No signup, no watermark, no limits.
