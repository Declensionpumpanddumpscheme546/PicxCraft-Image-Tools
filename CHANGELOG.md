## [1.0.0] - 2024-07-30

### Added
- Initial release of PicxCraft Android app
- 114+ free image tools accessible via WebView
- **Image Compression Tools**
  - Compress images to exact KB sizes (20KB, 50KB, 100KB, 200KB, 500KB, 1MB)
  - Lossy and lossless compression options
  - Batch compression support
- **Image Resizing Tools**
  - Resize by pixels, percentage, cm, mm, inches
  - Social media presets (Instagram, YouTube, Facebook, Twitter/X, LinkedIn, TikTok, WhatsApp, Discord, Telegram, Pinterest)
  - Passport photo maker with multi-country templates
- **Image Format Converter**
  - PNG to JPG / JPG to PNG
  - WEBP conversions
  - HEIC to JPG (iPhone photos)
  - TIFF to JPG / AVIF to JPG
  - GIF to PNG / Image to PDF
  - BMP and ICO conversions
- **Image Editing Tools**
  - Crop (free-form, circle, square)
  - Rotate and flip
  - Add borders
  - Split and merge images
  - Add text and watermarks
- **Image Filters & Effects**
  - Remove background
  - Blur (full, background, face)
  - Sharpen
  - Grayscale and sepia
  - Pixelate and censor
  - Brightness and contrast adjustment
  - Vignette effect
- **OCR & Advanced Tools**
  - Image to text (OCR)
  - QR code generator
  - Color picker
  - Image DPI checker
- **Android App Features**
  - Full WebView implementation
  - Native file picker (camera and gallery)
  - Download manager integration
  - Geolocation support
  - Cookie and session persistence
  - Hardware back button navigation
  - Material Design with adaptive icons
- **GitHub Actions CI/CD**
  - Automated APK builds on push
  - Auto-release creation
- **Documentation**
  - SEO-optimized README
  - Screenshots and preview GIF
  - MIT License
